# Method reference graphics sources

OmniGraffle sources (`.graffle`, `.ograph`) of the diagrams used in the aim42
method reference, taken over from the archived
[aim42/aim42](https://github.com/aim42/aim42/tree/master/graphics) repository
(`graphics/`, without `zz-deprecated/`). The exported images live in
`/images/patterns/`. This folder is excluded from the Jekyll build.
