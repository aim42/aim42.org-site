This content is open source! The source is hosted under the aim42 organization on GitHub.

If you want to help by improving upon it, fork the project, revise the content, then send a pull request.

\[github\] Source
: aim42 currently provides a *method reference*, the asciidoc sources are hosted at [GitHub under the aim42 organization](https://github.com/aim42/aim42).

\[bolt\] Issues
: Look over [our open issues](https://github.com/aim42/aim42/issues), pick one, fork the repository and resolve the issue. Send over a pull request!
