{% comment %} section-hero — unified hero card for every aim42 page that announces a section or a single item. One component drives: - Index and section pages (/patterns/, the phase pages /patterns//, /glossary/) via the aim42-page layout - Single pattern pages (/patterns//) via the pattern layout Section identity comes from the data-section attribute, which sets a CSS custom property --cat. Phase pages and patterns use their phase's colour, so a pattern shares the colour of the phase it belongs to. Required: section Color key. One of: analyze | evaluate | improve | crosscutting | patterns | reference (defaults to reference) title H1 text (plain; escaped here). Optional: eyebrow_label Small uppercase label above the title ("Phase", the phase name, …). eyebrow_href Link target for the eyebrow (typically the index or phase page). lede Single paragraph of plain text shown below the title. chips_html Pre-rendered HTML for the chip row (categories, stub badge). meta Inline metadata line (e.g. counts). HTML allowed. Example (phase page): {% raw %}{% include aim42/section-hero.html section="analyze" title="Analyze" eyebrow_label="Phase" eyebrow_href="/patterns/" lede="Find issues, risks and technical debt in the system and its organization." %}{% endraw %} Example (pattern page): {% raw %}{% capture chips %}stub{% endcapture %} {% include aim42/section-hero.html section=page.phase title=page.title eyebrow_label=phase.title eyebrow_href=phase.url chips_html=chips %}{% endraw %} {% endcomment %}
